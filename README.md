# Apps

Support and privacy pages for the iPhone apps of Marius van Dam, served with GitHub Pages at https://mariusvandam.github.io/apps/.

Each app has its own folder with `support.html`, `privacy.html` and `icon.png`; `stijl.css` is shared. Add a new app as a new folder and a new card in `index.html`.

The English pages sit in the app folder. Every other language has its own subfolder with the same two pages, and every page has a language bar at the top. The pages are generated: edit the texts in `scripts/bouw-site.py` of the app project and run it, instead of editing the HTML here.

| App | Languages | Support | Privacy |
|---|---|---|---|
| Ladon | en, nl, de, fr, es, pt, ja | https://mariusvandam.github.io/apps/ladon/support.html | https://mariusvandam.github.io/apps/ladon/privacy.html |

Other languages: replace `ladon/` with `ladon/nl/`, `ladon/de/` and so on.
