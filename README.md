# Apps

Support and privacy pages for the iPhone apps of Marius van Dam, served with GitHub Pages at https://mariusvandam.github.io/apps/.

Each app has its own folder with `support.html`, `privacy.html` and `icon.png`; `stijl.css` is shared. Add a new app as a new folder and a new card in `index.html`.

| App | Support | Privacy |
|---|---|---|
| Ladon | https://mariusvandam.github.io/apps/ladon/support.html | https://mariusvandam.github.io/apps/ladon/privacy.html |
